# Project skills

These skills are project-owned Copilot workflows for the CivicActions homesite rebuild. They are intentionally self-contained and do not depend on a personal agent framework.

- `omnichannel-sdc`: create or update a Canvas-ready SDC
- `canvas-verify`: verify Drupal and Canvas registration
- `storybook-story`: create a theme-local Storybook story
- `legacy-compare`: compare public legacy behavior with the rebuild
- `theme-lint`: run focused frontend validation

Personal plans and scratchpads remain outside version control through each developer's local Git exclude file.
